# 「帮我选」功能说明

## 功能定位

「帮我选」位于「选项怎么选」页面下方，用于帮助已经看过对比、但仍然拿不准的用户做选择。

它不是聊天机器人，也不要求用户输入一段文字。用户只需要选择当前最关注的一项：

- 最快收到；
- 价格更低；
- 售后更灵活；
- 品牌渠道优先；
- 成色性价比。

## 推荐方式

页面根据当前商品、尺码和包装下的可购买选项进行匹配，并展示：

1. 更适合当前关注点的购买选项；
2. 推荐理由；
3. 需要接受的取舍；
4. 返回对比或继续选择的入口。

## 示例

| 关注点 | 推荐方向 | 必须说明的取舍 |
|---|---|---|
| 最快收到 | 当前预计到货最快的选项 | 预计时间不是确定承诺 |
| 价格更低 | 当前价格最低的选项 | 成色、渠道或售后可能不同 |
| 售后更灵活 | 页面展示售后权益更完整的选项 | 到货可能更慢或价格更高 |
| 品牌渠道优先 | 品牌官方或品牌专供 | 不一定是最低价 |
| 成色性价比 | 95 分等成色选项 | 并非全新，需确认成色规则 |

## 展示原则

- 只使用当前页面已经展示的信息；
- 不使用“绝对最优”“一定到货”等承诺；
- 推荐结果必须同时写出理由和取舍；
- 用户可以随时返回对比并选择其他购买选项；
- 最终价格、库存和权益以订单页为准。
