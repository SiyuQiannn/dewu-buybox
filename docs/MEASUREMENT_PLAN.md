# 指标与验证计划

> 本文描述“如果功能上线，应该如何验证”，不代表项目已经取得真实业务结果。

## 1. 核心假设

为犹豫用户提供解释式对比和推荐，可以降低购买选项的理解成本，并帮助他们继续进入确认订单，而不会显著打扰高意向用户。

## 2. 核心漏斗

```text
进入购买选项页
  ├─ 直接选择购买选项 → 确认订单
  └─ 点击「选项怎么选」
       → 查看当前选项对比
       → 展开 Chip / 使用「帮我选」
       → 选择购买选项
       → 确认订单
```

## 3. 核心指标

### 北极星指标

购买选项页到确认订单页转化率。

### 效率指标

- 购买选项页平均决策时长；
- 反复切换购买选项次数；
- 进入辅助页后的继续下单率。

### 解释需求

- 「选项怎么选」入口点击率；
- 不同类型 Chip 点击率；
- 当前选项说明页访问率；
- 「帮我选」触发率。

### 推荐质量

- 推荐结果采纳率；
- 修改需求或重新推荐率；
- 推荐后仍返回对比的比例。

### 售后预期

- 查验和快速到货相关咨询量；
- 渠道标签相关咨询量；
- 售后权益相关咨询量；
- 因规则理解偏差产生的投诉或退款原因变化。

## 4. 建议埋点

| 事件 | 关键属性 |
|---|---|
| `buybox_guide_exposure` | 商品、尺码、选项数量、选项类型 |
| `buybox_guide_click` | 入口位置、页面停留时间 |
| `buybox_option_expand` | 选项类型、价格、预计到货 |
| `buybox_chip_click` | Chip 类型、选项类型 |
| `buybox_assistant_submit` | 用户选择的关注点 |
| `buybox_recommendation_show` | 推荐选项、关注点、推荐理由 |
| `buybox_recommendation_accept` | 推荐选项、是否进入确认订单 |

## 5. 实验设计

- 对照组：现有购买选项页；
- 实验组：增加辅助入口、解释式对比和「帮我选」；
- 分层：选项数量、跨境、95 分、快速到货、价格带；
- Guardrail：主购买页直接下单率、页面退出率、投诉与退款相关指标；
- 观察周期：覆盖工作日、周末和主要类目，不在概念项目中虚构具体周期或样本量。

## 6. 决策规则

- 辅助入口点击高、继续下单低：说明解释页可能过重或没有回答关键问题；
- Chip 点击集中：应把高频解释前置，减少低价值内容；
- 推荐触发高、采纳低：检查偏好提取、推荐理由或选项匹配；
- 总转化无改善但咨询下降：功能可能主要提升预期管理，需要重新评估价值；
- 主购买链路转化下降：降低入口干扰，或仅在用户反复切换选项时提示辅助入口。
