# 得物 Buybox 购买选项决策体验优化

同一个商品出现多个价格、渠道、成色和到货时间时，用户能看到信息，却不一定知道差异在哪里。

本项目围绕得物“尺码 + 购买选项”页面，设计「选项怎么选」辅助入口：先说明共同保障，再比较当前选项；具体标签可以点开解释，拿不准时也可以按自己最关注的点获得推荐。

## 在线体验

[https://SiyuQiannn.github.io/dewu-buybox/](https://SiyuQiannn.github.io/dewu-buybox/)

网页内包含：

- 产品故事与问题拆解；
- 沿用原版视觉与信息密度的可点击原型；
- “最快收到、价格更低、售后更灵活”等关注点推荐；
- 产品判断、功能优先级和验证思路；
- 可切换章节的完整 PRD；
- 并排呈现的四个终版原型页面。

## 核心方案

```text
购买选项页
  ├─ 直接选择购买选项 → 确认订单
  └─ 选项怎么选
       ├─ 平台品质保障
       ├─ 当前选项对比
       ├─ 标签就地解释
       ├─ 按关注点帮我选
       └─ 全部购买选项说明
```

## 设计原则

- 保留原来的“立即购买”主路径；
- 不展示具体供应商身份，只解释用户能感知的差异；
- 共同保障先说，价格、时效、渠道、成色和售后再比较；
- 高频信息直接展示，具体规则按需展开；
- 推荐同时说明理由与取舍，用户仍然自己做最终选择。
